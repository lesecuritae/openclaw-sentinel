# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone,
regardless of background, identity, experience, or personal characteristics.

## Expected behavior

Be respectful, constructive, patient, and focused on the technical work. Welcome questions,
accept feedback gracefully, respect privacy, and prioritize user safety. Harassment, threats,
discrimination, doxxing, sexualized conduct, and publishing another person's private information
are unacceptable.

## Enforcement

Report conduct concerns privately to the repository maintainers through the contact method in the
maintainer's GitHub profile. Maintainers may edit or remove contributions and temporarily or
permanently restrict participation when behavior is harmful. Reports will be handled as privately
and fairly as practical.

This project uses the spirit of the Contributor Covenant: an open community requires empathy,
clear boundaries, and proportionate enforcement.
