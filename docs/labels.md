# Suggested GitHub labels

| Label | Purpose |
| --- | --- |
| `bug` | Confirmed defect |
| `enhancement` | Feature or improvement |
| `security` | Non-sensitive security hardening only |
| `collector` | Event source integration |
| `intelligence` | Reputation or enrichment provider |
| `action-provider` | Enforcement or challenge adapter |
| `documentation` | Documentation-only work |
| `good first issue` | Small, well-scoped contribution |
| `help wanted` | Maintainer requests community help |

Potential vulnerabilities must be reported privately as described in `SECURITY.md`, not labeled
in a public issue.
