# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Report a
vulnerability** private advisory flow for this repository. Include the affected version, impact,
reproduction steps, and any suggested mitigation. Remove credentials and personal data from the
report.

Maintainers will acknowledge a complete report within seven days, investigate it, and coordinate
disclosure and remediation with the reporter. Please allow a reasonable remediation window before
public disclosure.

## Supported versions

Until the first stable release, security fixes target the latest commit on `main`. Sentinel can
control enforcement infrastructure; deploy it with actions disabled first, least privilege,
network restrictions, authentication, backups, and independent recovery access.
