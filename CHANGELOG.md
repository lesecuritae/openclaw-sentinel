# Changelog

All notable changes are documented here. The project follows semantic versioning after its first
stable release.

## [Unreleased]

### Added

- Public project governance, security policy, plugin contracts, examples, documentation, CI
  security checks, and original branding.

## [0.1.5] - 2026-09-04

### Added

- Structured HAProxy request event pipeline over UDP JSON/syslog.
- Request-level schema and SQLite migration.
- Login brute-force and distinct-path scanner detection.

## [0.1.0] - 2026-09-04

### Added

- Initial Sentinel core, HAProxy runtime integration, rule/risk/policy engines, SQLite memory,
  action adapters, LLM gateway, MCP boundary, Docker deployment and tests.
